# ShopOS technical audit — executive summary

**Scope:** static review of the checked-out workspace plus local install/build/lint/type-check/tests. Application code was not intentionally edited; this audit adds documentation only. Runtime Supabase configuration, production secrets, database state, deployed security settings, and production behavior were not accessible and are **UNVERIFIED**. The build describes this as a TanStack Start app, not a pure Vite SPA ([package.json](../../package.json#L16-L88), [vite.config.ts](../../vite.config.ts#L1-L13)).

## Verdict

**Yellow / not yet production-verified.** Core shop workflows are implemented: check-in, repair-order board, guarded transitions, bays, technician assignment, digital inspections, tokenized customer approvals, staff roles, and WhatsApp integration paths ([roadmap.md](../../roadmap.md#L5-L14), [drizzle/migrations/0001_shopos_business_functions.sql](../../drizzle/migrations/0001_shopos_business_functions.sql#L84-L340)). The original build/type-check/tests passed and ESLint failed; see the current [validation report](08-validation-report.md) for revalidation after the follow-up changes. WhatsApp is now simulated by default; live delivery requires explicit `WHATSAPP_MODE=live` ([src/api/whatsapp.server.ts](../../src/api/whatsapp.server.ts#L84-L112)). Production deployment, backups, and active Supabase state are **UNVERIFIED**.

## Follow-up implementation status

The current local `LOVABLE_DB_MIGRATION_URL` is an HTTPS URL rather than a Postgres URI, so Drizzle cannot safely reconcile or run future migrations until it is replaced locally. See the [production readiness runbook](../operations/production-readiness.md). ## Scope and key caveats

- This app uses Vite + React 19 + TypeScript + Tailwind CSS 4 + shadcn/Radix-style components + TanStack Start/Router + TanStack Query + Supabase. It does **not** use React Router; the router is TanStack Router ([package.json](../../package.json#L16-L88), [components.json](../../components.json#L1-L22), [src/router.tsx](../../src/router.tsx#L1-L16)).
- Server-only code uses `SUPABASE_SERVICE_ROLE_KEY`; the browser client uses the public `VITE_SUPABASE_PUBLISHABLE_KEY`. No service-role value was found in the frontend source scan. **UNVERIFIED:** deployed secret bindings and frontend bundle contents were not independently inspected. [Browser client](../../src/integrations/supabase/client.ts#L50-L74) · [server client](../../src/integrations/supabase/client.server.ts#L32-L59)
- The baseline schema defines 19 public tables and one enum; migration 0005 adds the RLS-enabled `api_rate_limits` table and updates the message status check. Live application is **UNVERIFIED**. [Core schema](../../drizzle/migrations/0000_shopos_core_schema.sql#L1-L379) · [follow-up migration](../../drizzle/migrations/0005_security_limits_and_staff_activation.sql#L5-L146) · [journal](../../drizzle/migrations/meta/_journal.json#L32-L39)
- Git chronology cannot be reconstructed: the workspace had no `.git` metadata at audit time, and `AGENTS.md` itself says the current implementation was rebuilt from a Vue/Express source. Only migration order and roadmap checkboxes support a logical build sequence; commit-by-commit history is **UNVERIFIED**. [AGENTS.md](../../AGENTS.md#L9-L18) · [migration directory](../../drizzle/migrations/0000_shopos_core_schema.sql#L1-L4)
